# Screen Plug releases

Downloads for [Screen Plug](https://screenplug.app), a macOS menu bar app that keeps your Mac awake and tidies your displays.

Get the latest DMG from [Releases](https://github.com/bytefella/screenplug-releases/releases/latest). The app also updates itself in place.

This repository only hosts release builds. Screen Plug is proprietary software; the source code is not published.
